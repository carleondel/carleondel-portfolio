Copy this file to `content/blog/your-post-slug.md` (without the leading underscore)
and write in Markdown. The file name becomes the URL: `/blog/your-post-slug`.

- `lang`: `en` or `es`. The post shows up in both versions of the site, tagged
  with its language.
- `draft: true` shows the post only in `npm run dev`. Set it to `false` (or remove it)
  to publish.

## A heading

Regular **Markdown**: links, lists, `code`, code blocks, images from `public/`, quotes.
